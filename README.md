# Beyond The Screen

A responsive landing page / hero page for a personality-based movie, series and animation discovery concept.

## Files

- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and the “coming soon” dialog

## Run locally

No build tools or dependencies are required. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Notes

- The page uses Google Fonts and a few remote Unsplash images, so an internet connection is needed for those assets.
- The personality test and recommendation engine are not implemented yet. The main call-to-action currently opens an informational dialog.
